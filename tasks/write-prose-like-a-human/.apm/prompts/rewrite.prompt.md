## What is the goal

Rewrite the text the user refers to so it reads as human prose.

## What to do

- Use the source the user names. That may be a linked file, the previous response, a selection, or any other text they point at.
- If the source is unclear, ask which text to rewrite.
- Apply the write-prose-like-a-human skill.
- Keep the meaning, facts, and scope of the source.
- Return the rewrite. When the source is a file, update that file.

## What not to do

- Do not add ideas, claims, or emphasis that were not in the source.
- Do not explain the rewrite unless the user asks.
