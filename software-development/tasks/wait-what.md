description: Repitch the current idea in plain, simple words so the user can check it.
---

## What is the goal

The user lost track of the idea or does not understand it. Pitch the idea again
so that the user can understand it on the first read and confirm or correct it.

## What to do

- Find the idea that is currently under discussion. If you cannot identify
	it, ask the user which idea to repitch.
- Pitch it again from the start. Do not assume that the user remembers the
	earlier discussion.
- Say what the idea is, which problem it solves, and what changes for the user.
- Name the most important trade-off or open question, if there is one.
- Write in ASD-STE100 Simplified Technical English: short sentences, one topic
	per sentence, active voice, and common words with one meaning each.
- Apply the write-prose-like-a-human skill.
- End with a short question that asks the user to confirm or correct the pitch.

## What not to do

- Do not add new ideas, scope, or decisions.
- Do not repeat the earlier explanation in different words; build the pitch
	again from the idea itself.
- Do not use jargon or abbreviations unless you explain them.
